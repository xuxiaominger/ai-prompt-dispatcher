# 🚀 AI Prompt Dispatcher

👉 一个输入框，一次提问，同时调用多个 AI

🌐 在线访问：
https://xuxiaominger.github.io/ai-prompt-dispatcher/

---

## ✨ 功能特点

- ✅ 单输入框，极简设计  
- ✅ 一次输入，同时打开多个 AI  
- ✅ 自动复制 Prompt  
- ✅ 支持主流 AI 平台  

支持平台：

- ChatGPT  
- Gemini  
- Kimi  
- Grok  
- 通义千问  
- 腾讯元宝  

---

## 🧠 使用方式

1. 输入你的问题（Prompt）
2. 点击 GO
3. 自动打开多个 AI 页面
4. 粘贴即可获得多模型答案

---

## 🚀 为什么要用？

传统方式：

- 来回切换 AI  
- 重复输入问题  
- 浪费时间  

本工具：

👉 一次输入 → 多AI同时响应  
👉 快速对比最优答案  
👉 效率提升 3 倍以上
